This is a classic Brick Breaker (or Breakout) game, built with HTML5 Canvas and plain JavaScript.

This project was originally written for the CodeHS platform and its specific graphics library. This repository contains a converted version that uses the standard HTML5 Canvas API, allowing it to run in any modern web browser.
link to the game: https://arianghalenoei-lab.github.io/brick-breaker-game/

## 🕹️ How to Play

* **Move your mouse** left and right to control the paddle.
* **Bounce the ball** off the paddle to break all the bricks.
* Don't let the ball fall past your paddle, or it's **Game Over**!

## 💻 Tech Used

* **HTML5** (via the `<canvas>` element)
* **CSS3** (for basic styling and centering the game)
* **JavaScript** (for all game logic, physics, and drawing)
